# NEXORA — Corporate Business Website

A modern and responsive corporate business website designed to showcase professional services, build brand identity, and deliver a smooth user experience across all devices.

## Live Demo

[View the live website](https://mkaceduet-hub.github.io/nexora-corporate-website/)

## Overview

NEXORA is a fictional corporate website concept created as a front-end portfolio project. It features a clean visual identity, responsive layouts, and clear calls to action for a professional business presence.

## Features

- Responsive layout for desktop, tablet, and mobile
- Modern corporate design and typography
- Mobile navigation menu
- About, services, approach, and project sections
- Contact form interaction (front-end demo only)
- Semantic HTML and accessible form labels
- Lightweight vanilla JavaScript

## Built With

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Unsplash images

## Project Files

- `index.html` — website structure and content
- `style.css` — layout, visual design, and responsive styling
- `script.js` — mobile navigation and demo form interactions

## Getting Started

1. Download or clone this repository.
2. Open the project folder in Sublime Text or your preferred editor.
3. Open `index.html` in your browser.

No build tools or package installation are required.

## Important Notes

- This is a fictional portfolio concept, not a real company website.
- The contact form is a front-end demonstration. It does not send or store messages.
- Replace the demo email address in `index.html` before using this project for a real business.
- Images are loaded from Unsplash URLs and require an internet connection.
